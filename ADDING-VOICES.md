# Добавление голосов SmartVoice

Каталог: `catalog.json`. Он читается SmartVoice UMEDJON 5.2.53-TJ (4169) и новее по HTTPS. Репозиторий один для всех голосов. Новые языки и модели не требуют нового APK. Доступны только Microsoft, Google и «Vocalizer — голоса из папки». Обычный Vocalizer открывает прежний загрузчик приложения со всеми вариантами качества.

## Текущий опубликованный выпуск

В voices-001 проверены 16 ZIP, содержащие 15 уникальных Microsoft-моделей. Два Xiaobei имеют одинаковый SHA-256 и дают одну карточку; сами архивы не удаляются. Dilara/Farid — персидский, Hamed — арабский, Madina/Sardor — узбекский. Все стандартные китайские и кантонские варианты сгруппированы в интерфейсе под «Китайский», но их внутренние коды zh-CN, региональные варианты и yue-CN сохраняются раздельно. Yelda/Tingting ранее удалены владельцем и отсутствуют в каталоге. Google и «Vocalizer — голоса из папки» пока пусты.

Для китайских Microsoft-пакетов с ресурсами BR и расширенными языковыми метками требуется SmartVoice 5.2.55-TJ (4171). Каталог остаётся читаемым прежними 5.2.53/54; неподдерживаемые ими новые пакеты нельзя установить до обновления.

## Порядок действий владельца

1. Подготовьте ZIP в формате, который успешно импортируется текущим SmartVoice. Поддерживаются пакеты Microsoft и Google, экспорт SmartVoice, совместимые полные конфигурации Google и коллекции, а для Vocalizer — согласованные пары HDR/DAT. Произвольный ZIP не считается моделью. Проверка ресурсов не заменяет прослушивание на телефоне.
2. Убедитесь, что у вас есть разрешение распространять содержимое. Автоматическая проверка не определяет лицензионные права.
3. Можно продолжать существующий опубликованный voices-001: Releases → Edit → загрузить новый ZIP → Update release. Каталог обновится автоматически, Run workflow не требуется. Новый тег нужен только если вы сами хотите отдельный выпуск. Разрешается несколько ZIP в одном выпуске, один пакет с несколькими моделями и варианты качества.
4. Для предварительной проверки сохраните черновик, затем Actions → Update SmartVoice voice catalog → Run workflow → main → Run workflow. Простая загрузка вложения в Draft не запускает Actions.
5. Дождитесь зелёного результата. Откройте `checks/needs-review.json` и карточки в `catalog.json`. Если проверка не прошла, файл не попадёт в пользовательский каталог. Исправьте пакет или добавьте достоверные метаданные, затем повторите запуск.
6. Для нового черновика после собственной проверки нажмите **Publish release**. Для существующего опубликованного выпуска достаточно **Update release**. После успешного Actions проверенные записи имеют published=true. В приложении используйте «Обновить каталог» или откройте раздел повторно.

Для старых тегов с прежним workflow предусмотрено автоматическое продолжение из main: после завершения старого запуска появится «Refresh voice catalog after legacy release». Его результат Success подтверждает сохранение каталога. Исторический красный запуск старого тега не удаляется; ручной перезапуск не требуется. Для новых тегов используется исправленный catalog.yml. При гонке изменений main каталог пересчитывается из последнего коммита, без force-push.

Никогда не заменяйте байты уже опубликованного вложения тем же именем. Для исправленной модели создайте новое вложение/выпуск. Перед удалением старых публичных архивов учтите незавершённые загрузки пользователей. Скрипт старые архивы не удаляет.

## Если метаданных не хватает

Редактируйте `metadata-overrides.json`: ключ — SHA-256 всего ZIP, значение — подтверждённые поля. Пример (вместо показанного ключа нужен настоящий SHA-256):

```json
{
  "полный_sha256_архива": {
    "provider": "microsoft",
    "name": "Microsoft Example",
    "locale": "uz-UZ",
    "quality": "unspecified",
    "gender": "female",
    "sampleUrl": "https://github.com/UMEDJON12/smartvoice-voice-library/releases/download/voices-002/example.mp3"
  }
}
```

Пол и образец необязательны. Производитель, известный язык и качество не могут противоречить результату импортёра. Для нескольких моделей одного ZIP можно добавить объект `models`, ключи которого — точные коды моделей из отчёта. Значение содержит такие же подтверждённые поля. Не угадывайте производителя по имени архива. Неизвестный формат сначала требует поддержки в импортёре и обновления APK; новая категория производителя не создаётся автоматически.

`sampleUrl` допускает только HTTPS-вложение опубликованного выпуска этого репозитория. Убедитесь, что это звуковой файл. Если образца нет, оставьте пустым — кнопка не появится. Образец не требует скачивания модели.

## Что делает автоматизация

Запускается при публикации/редактировании выпуска, вручную и при изменении инструментов/метаданных в main. Проверяет GitHub SHA-256, размер, CRC, пути, лимит распаковки, затем вызывает `tools/import-validator.jar` — фактический импортёр SmartVoice без синтеза и выполнения кода из архива. Неизвестные и несовместимые пакеты попадают в needs-review. При временной сетевой ошибке прежний каталог сохраняется.

Модель определяется по производителю, внутреннему коду и качеству, а не по ZIP. Одинаковое содержимое с другим именем не создаёт дубликат. Новое содержимое той же модели увеличивает packageVersion и сохраняет историю идентификаторов, чтобы приложение распознало установленную вручную предыдущую модель. Публичный пакет не скрывается черновым обновлением. Новый опубликованный пакет имеет преимущество над прежним. Для новой версии сохраняйте код модели и достоверное качество.

На телефоне проверяются контрольная сумма и реальное содержимое, затем используется прежний импортёр и правила автоназначения. Уже установленный голос не загружается без подтверждения. Подготовка замены выполняется до переключения, с сохранением прежних идентификаторов и настроек. При ошибке старая модель остаётся. Сеть/импорт работают вне UI-потока. Последний корректный каталог доступен без связи. Незавершённая загрузка продолжается при повторном выборе, если сервер поддерживает Range; отмена не удаляет пользовательские ZIP.

## Пределы проверки

verificationStatus=verified означает проверенный архив и успешный импорт текущим кодом. verificationScope явно отмечает, что реальное звучание на Android не проверяется GitHub runner. Совместимость нативного движка и корректность произношения подтверждаются на телефоне. Microsoft/Google требуют Android 8+ и arm64, обычный Vocalizer сохраняет прежние ограничения. Общая доступность GitHub и скорость канала зависят от сети.

## Обновление самого валидатора

Исходники и команда воспроизводимой сборки входят в полный исходный код SmartVoice: `offline_build_tools/build_catalog_validator.py`. Нужны штатные зависимости сборки проекта, JDK и `SMARTVOICE_BUILD_JDK`. Полученный JAR заменяет tools/import-validator.jar. Он не содержит ключей, голосов и нативных библиотек. Новый формат архива нельзя объявлять совместимым одной ручной отметкой, минуя импортёр.

## Реальные образцы перед скачиванием — 5.2.55

Для текущих 15 Microsoft-моделей сформированы короткие настоящие речевые образцы. Они находятся в samples/, их точная связь с кодом модели, качеством и SHA-256 исходного ZIP записана в samples/index.json. Никакие чужие голоса или облачный синтез вместо выбранной модели не используются.

При добавлении нового поддерживаемого Microsoft ZIP Actions запускает исходную модель через официальный Embedded Speech SDK 1.45.0 — той же версии, что встроена в приложение. Это Linux/x64-проверка и получение настоящего PCM; физическое Android-устройство она не заменяет. SDK для рабочего сервера загружается по фиксированному официальному адресу и проверяется по SHA-256. В APK большие новые библиотеки не добавляются. Исходные параметры берутся только из самого пакета и не попадают в публичные отчёты.

При наличии проверенного текста данного языка из PCM получается небольшой MP3. Он вместе с индексом и каталогом сохраняется одним коммитом. Повторно готовый образец с тем же кодом, качеством и SHA-256 ZIP не создаётся. При отсутствии реального совместимого рендерера или подходящего текста кнопки образца нет. Достоверные образцы других уже разрешённых производителей можно привязать через проверенный индекс или прежний sampleUrl опубликованного вложения.

Для совместимости со старыми APK репозиторные образцы передаются в sampleUrlV2; 5.2.55 поддерживает только HTTPS-файлы samples/ этого репозитория. Полный ZIP ради прослушивания телефон не загружает. В программе та же кнопка позволяет остановить образец. Прежние образцы обычного Vocalizer сохранены.

## Диагностика

checks/needs-review.json содержит имя и ID ZIP, формат, этап, класс/код и понятную причину отказа, безопасную выдержку stderr и отсутствующие ресурсы. Пароли, параметры лицензии, токены и абсолютные приватные пути не публикуются. В checks/archive-inspection.json также виден результат формирования образцов: available, unavailable или failed, а при проблеме — точный этап. Настоящий отказ синтеза новой модели не выдаётся за успешную проверку.
